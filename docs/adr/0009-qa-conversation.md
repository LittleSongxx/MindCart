# ADR-009：QA 多轮会话（最近 3 轮 + 字符预算）

日期：2026-09-16 ｜ 状态：已实施

## 设计

- `qa_conversation`（user_id/title/时间）+ `shopping_qa.conversation_id/round_no`
- 上下文组装：最近 3 轮 Q（截100字）+ A（截300字），总预算 1200 字符，超出丢最旧轮
- 首问建会话（标题=首问截50字）；roundNo 按 conversation 内计数

## 边界（面试问法的答案就在这）

- 为什么不长期记忆：单店导购场景无跨会话记忆需求；长期记忆要解决写入甄别/冲突/遗忘，超出必要
- 预算用字符不用 token：演示级近似，可解释（1 中文字≈1-2 token）；精确 token 计数在 P0 token 采集落地后可换
- 压缩不改变权威事实：历史答案只是 prompt 参考，答案仍受 RAG 检索门控约束
