# ADR-007：混合检索（BM25 + 向量 + RRF）

日期：2026-09-16 ｜ 状态：已实施

## 为什么（真实检索缺陷）

商品语料含大量编号/型号/数字 token（M3、256G、SP2026…）。稠密向量对这类**字面精确查询**
会把「同类商品」排在目标前面（语义相似≠字面命中）；BM25 恰好补这块。
这是面经 H2 题族「BM25 补上了什么」在本地语料上的真实对应。

## 怎么做

- 分词：ASCII 字母数字连串保留整 token（编号不断开），中文 bigram（HybridRetrievalService，纯函数可单测）
- Okapi BM25（k1=1.5, b=0.75）对全部 READY 切片打分（演示量级内存计算；上量换倒排/全文索引）
- RRF 融合：score=Σ 1/(60+rank)，**只融名次不融不可比的分数**
- 可答性门控升级：余弦 ≥0.5 **或** BM25 top5 命中（字面精确查询不应被语义阈值误拒）
- `mode=dense|hybrid` 参数保留对照通道（评测 A/B 用）

## 证据

单测 4/4（分词/字面命中优先/双通道一致者优先/空通道）；
严格谓词口径 A/B：hybrid 3/5 vs dense 2/5；校准口径双通道 5/5（小语料饱和，如实记录）。
发现（未掩盖）：切片内容不含商品编号 → 纯编号查询两头都失败，属语料侧缺口（切片标题拼编号可解，待办）。
