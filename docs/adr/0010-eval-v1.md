# ADR-010：评测 v1 —— 确定性断言判分

日期：2026-09-16 ｜ 状态：已实施并实跑

## 设计（与 Smartlect quality-v2 的关系：借鉴骨架，砍到必要）

- **只报代码可判的硬断言**，不引入 LLM judge：导购的预算/在售/有货/金标命中、QA 的拒答谓词、
  检索的内容谓词——全部确定性，零 judge 成本零 judge 偏差
- 每指标印分母；n<50 不报置信区间（解释力不足，如实注明）
- 题目按失败类组织：预算约束/金标命中/空集诚实/注入对抗/库存边界/拒答/检索A/B

## 两次评测器校准的实录（评测器本身也要被质疑）

1. 拒答标记词表首轮 2 例假阴性——回答确实拒答但用词不在表内（"没有覆盖到"）→ 扩表后 5/5。
   教训与 Smartlect judge 校准战役同构：**判分器未校准前，分数不可信**。
2. 检索谓词首轮 all-of 过严（语料用「质保」而非「保修」）→ 改 any-of；
   语料不含商品编号 → 编号类用例改型号字串，编号缺口记为语料侧待办。

## 诚实呈现

- 校准后：拒答 5/5、检索双通道 5/5（小语料饱和）；严格口径 A/B 差异 3/5 vs 2/5 如实记录
- 分数用于回归对比（改提示词/换模型前后），不用于宣称绝对水平
- 升级路径：集子扩到 50+ 且出现语义面判分需求时，才引入 judge + 校准集 + trials 方差
