## 二、有意不修（取舍记录）

1. **JWT 无吊销/登出无服务端失效**：72h 短时效 + 网关集中鉴权是声明的取舍（TokenService 注释），引入 Redis 黑名单属过度设计，不改。
2. **平台收款记"第一个管理员"账户**：演示口径，真实方案需要独立平台账户体系，超出范围。
3. **幂等表/事件账本无 TTL**：ledger 是对账数据源需长期保留；幂等表量级小。有需要再加归档任务。
4. **Nacos 未开鉴权**：仅 127.0.0.1 绑定；集群部署时另行开启（开启需同步配置 identity key，影响面大）。
5. **成长报告全表加载**：管理端低频接口，数据量到量级再做 SQL 聚合。
6. **多轮轮次号 nextRoundNo 并发可重号**：轮次号仅展示用途，会话内容完整性由 conversationId 保证。
